Crypto Toolkit

Encryption, hashing and breach checking, all running in your browser.

Algorithm: AES-256-GCM. Key derived with PBKDF2-SHA-256 (600,000 iterations) and a random 16-byte salt. A random 12-byte IV is used for every encryption.

How it works: your browser computes the SHA-1 hash of the password and sends only the first 5 characters of it to the Have I Been Pwned API. The API returns every hash that starts with those 5 characters, and your browser looks for a full match locally. The password itself is never sent.

Educational project. It has not been security audited, so do not rely on it to protect real secrets. Keep your password safe: encrypted text cannot be recovered without it.
